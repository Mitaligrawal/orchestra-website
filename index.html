Set the objective. Run the planner.

Choose a repository, describe what the agents should build, pick model and effort, then hit Run planner. The planner reads the repo and splits work across agents only when it is genuinely parallel — otherwise one agent does it.

Watch planner, sub-agents, and PRs

The run desk shows the planner stream, live sub-agents, and pull requests as work finishes. Track tokens and cost, stop or reset a run, and approve shell commands before they execute.

Isolated worktrees. You merge.

Each agent writes real files on its own branch in its own git worktree. Nothing reaches your branch until you merge. PRs appear in Orchestra as sub-agents finish their work.

Human in the loop

Every shell command asks for approval before it runs.

Your Claude Code

Opus or Sonnet, effort from low to max — via the CLI you already use.

Live observability

See agents working, token usage, and spend while the run is live.

Three steps to a run.

  1. 01

    Choose a repository

    Browse or open any local git repo. Orchestra works on real files in worktrees.

  2. 02

    Say what agents should build

    Write the objective, pick opus or sonnet, set effort, then run the planner.

  3. 03

    Approve, review, merge

    Approve shell prompts, watch sub-agents, then merge PRs when you are ready.

Requires Claude Code CLI (logged in) and git. Orchestra does not bundle a Claude subscription — it drives the claude already on your PATH.
